模型可以從原本的：

> **歷史回測 → 未來逐年模擬**

改成：

> **歷史回測 → 推估 N 年後終值分布**

也就是只回答：

> **「如果現在持有這一籃子股票，N 年後可能值多少？」**

而不產生中間每年的路徑。

---

# 一、我建議的整體架構

報表可以分成兩大區：

```text
                一籃子股票
                    │
          ┌─────────┴─────────┐
          ↓                   ↓
      歷史回測              未來N年推估
          │                   │
   Full History          N年後情境
   Common Period         ├─ Bear
   Dynamic Entry         ├─ Base
                        └─ Bull
          │                   │
          └─────────┬─────────┘
                    ↓
               統一報表
```

---

# 二、歷史部分維持前面的三種方式

## ① Full History

每支股票從自己最早可取得資料開始。

例如：

| 股票 | 起始日  | 歷史年數 |  CAGR |
| -- | ---- | ---: | ----: |
| A  | 2008 | 17.5 | 12.5% |
| B  | 2012 | 13.5 | 15.2% |
| C  | 2019 |  6.5 | 22.4% |

---

## ② Common Period

找所有股票共同存在的期間。

例如：

> 2019～2026

所有股票從同一天開始比較。

這是：

### **最公平的歷史比較**

---

## ③ Dynamic Entry

股票有資料之後才加入籃子。

這比較接近：

> 實際投資情境。

---

# 三、接下來增加「Future N-Year Forecast」

> 2026/08/19

使用者輸入：

N = 5

系統只輸出：

> **2031/08/19 的預估結果**

而不是：

2027
2028
2029
2030
2031

# 四、最重要：不要只用一個 CAGR

我建議使用：

## Bear / Base / Bull

例如：

| 情境   | 年化報酬假設 |
| ---- | -----: |
| Bear |     5% |
| Base |    10% |
| Bull |    15% |

如果目前資產：

> 1,000,000

N = 10：

### Bear

```text
1,000,000 × (1.05)^10
= 1,628,895
```

### Base

```text
1,000,000 × (1.10)^10
= 2,593,742
```

### Bull

```text
1,000,000 × (1.15)^10
= 4,045,558
```

這樣使用者只看到：

| N年後 | Bear | Base | Bull |
| --- | ---: | ---: | ---: |
| 10年 | 163萬 | 259萬 | 405萬 |

而不是一堆年度資料。

# 五、但「5% / 10% / 15%」不能人工亂設定

這是這個工具最重要的地方。

既然你已經有大量股票的歷史資料，我建議：

> **直接從歷史資料建立未來報酬情境。**

例如 Common Period 的歷史 CAGR：

```text
股票 A   12%
股票 B   15%
股票 C    8%
股票 D   21%
...
```

不要直接取平均。

應該取得：

```text
CAGR Distribution
```

例如：

```text
P10 = 5%
P25 = 8%
P50 = 12%
P75 = 17%
P90 = 24%
```

然後：

| 情境           | 歷史分位數 |
| ------------ | ----: |
| Bear         |   P10 |
| Conservative |   P25 |
| Base         |   P50 |
| Optimistic   |   P75 |
| Bull         |   P90 |

這樣「情境」是由歷史資料產生，而不是人工猜測。

---

# 六、但是我會再做一個重要調整

**不要直接用「個股 CAGR 的分布」預測組合。**

例如：

```text
A = 20%
B = 15%
C = 5%
D = 30%
```

不能直接：

```text
平均 = 17.5%
```

然後說：

> 未來組合 CAGR = 17.5%。

因為股票之間有：

* 權重
* 相關性
* 波動
* 極端報酬

所以我會從：

## Portfolio Historical Return

建立情境。

# 七、最推薦的方法：Historical Rolling N-Year Returns

這非常適合你的需求，而且**完全不需要模擬未來每一年**。

假設：

> N = 5 年

歷史資料有 2010～2026。

我們直接計算：

```text
2010 → 2015
2011 → 2016
2012 → 2017
2013 → 2018
...
2021 → 2026
```

每一段只產生一個：

> **5-Year Total Return**

例如：

| Period    | 5Y CAGR |
| --------- | ------: |
| 2010–2015 |    8.2% |
| 2011–2016 |   10.5% |
| 2012–2017 |   13.1% |
| 2013–2018 |    6.4% |
| 2014–2019 |   12.8% |
| 2015–2020 |   15.2% |
| 2016–2021 |   11.4% |
| ...       |     ... |

然後得到：

```text
P10
P25
P50
P75
P90
```

---

# 八、這個方法的優點非常大

因為它沒有回答：

> 2027 會漲多少？

也沒有回答：

> 2028 會漲多少？

它只回答：

> **歷史上，這個投資組合經歷一個 N 年期間時，結果通常落在哪裡？**

這正好符合你的要求。

# 十三、公式非常簡單

歷史 N 年 CAGR：

[
CAGR_N =
\left(\frac{NAV_{t+N}}{NAV_t}\right)^{1/N}-1
]

未來 N 年終值：

[
FV_N =
PV(1+r_N)^N
]

其中：

* (PV) = 目前投資組合價值
* (r_N) = 歷史 N-Year CAGR 所對應的情境
* (N) = 預測年數

**整個 Forecast Engine 不需要建立 2027、2028、2029……的模擬路徑。**

只需要：

```text
現在
 ↓
歷史 N-Year Return Distribution
 ↓
P10 / P25 / P50 / P75 / P90
 ↓
N 年後終值
```

## 我認為這會比原本的 `buyhold_forecast` 更合理

因為它的名稱也應該從：

> **Buy & Hold Forecast**

改成：

> **Historical N-Year Outcome Forecast**

它不是宣稱：

> 「未來一定會得到 X%」

而是：

> **「這個股票組合在歷史上經歷相同長度的投資期間時，曾經出現什麼樣的結果；以此建立 N 年後的情境範圍。」**

這個定位我認為**相當實用，而且比逐年 Monte Carlo 更符合現在想要的報表用途**。
